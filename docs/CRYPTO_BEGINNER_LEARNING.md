# 加密交易小白：边交易边学专业课

> 面向几乎没有金融背景、刚接触加密与 Strand 的人。  
> **本文是学习方法与术语地图，不是投资建议。** 加密与杠杆交易可能损失本金；请只用亏得起的钱。

相关文档：[PRODUCT_INTRO.md](./PRODUCT_INTRO.md) · [WEB_TOP_NAV.md](./WEB_TOP_NAV.md) · [LAUNCH_CHECKLIST.md](./LAUNCH_CHECKLIST.md)

## 1. 先定学习原则（比背单词重要）

| 原则 | 怎么做 |
|------|--------|
| **先理解资金，再理解行情** | 搞清「钱在哪、谁能动、亏到哪停」比预测涨跌更优先 |
| **一词一场景** | 每个术语至少对应一次真实操作或一次 Portfolio（资产）上的数字 |
| **小仓练习** | 用最小本金或模拟思路跑通流程，把「怕」变成「可观察」 |
| **只学当下需要的** | 今天开仓就学开仓相关词；别一次啃完整本金融课本 |
| **写学习笔记** | 每次交易后记：用了什么词、发生了什么、哪里没看懂 |

推荐节奏：**每周 2～3 个核心词 + 1 次完整操作复盘**，比一天刷 50 个术语更有效。

## 2. 用 Strand 当「活教材」

把产品页面当成教室：看见什么词，就当场查、当场记。

| 你在哪 | 能学到什么 |
|--------|------------|
| **Autopilot / Settings** | 账户、API、钱包、授权、保证金与 AI 费用为何分开 |
| **Trade** | 市价 / 限价 / 分批 / TWAP——「怎么下单」的差异 |
| **Portfolio（资产）** | 权益、盈亏、持仓、杠杆、回撤、暂停——结果怎么读 |
| **Strategy** | 风控硬闸（日亏、最大回撤）——规则如何保护你 |
| **Chat** | 用自然语言问行情，把口语翻译成专业说法（只读，不下单） |
| **Leaderboard** | 收益率如何横向比较（注意初始资金与时间窗） |

### 边用边学的四步循环

1. **操作前**：写下你打算做什么（例：存 $20 到 Hyperliquid 合约账户）  
2. **操作中**：遇到不懂的词 → 查本文第 4 节或 Chat「用小学生能懂的话解释 XXX」  
3. **操作后**：打开 Portfolio（资产），指着每一个数字说清含义  
4. **复盘**：一句话总结「今天新懂了什么」

## 3. 建议学习顺序（从生存到进阶）

### 阶段 A：别把本金弄丢（第 1 周）

目标：能安全完成「充值 → 授权 → 看余额 → 不乱开高杠杆」。

必学概念：

- 现货 vs 合约（永续）
- 钱包 / 交易所账户 / Agent 授权
- 保证金、可用余额、权益（Equity）
- 手续费 vs 本金（AI 分析费 vs 交易保证金）
- Preflight（启动前检查）为什么存在

练习：走完 [LAUNCH_CHECKLIST.md](./LAUNCH_CHECKLIST.md) 的勾选，每勾一项写一句「这是在防什么风险」。

### 阶段 B：读懂一张持仓（第 2～3 周）

目标：Portfolio（资产）上任意一笔持仓，你能解释「方向、数量、盈亏、强平大概在哪」。

必学概念：

- 多（Long）/ 空（Short）
- 开仓价、标记价（Mark）、未实现盈亏
- 杠杆、名义价值、保证金占用
- 强平价（Liquidation）直觉（不必先会公式，要先有「杠杆越高越危险」）
- 日亏限制、最大回撤、暂停交易

练习：假想自己开了一笔小多单，用纸笔算：价格跌 5%、杠杆 5x 时，保证金大概亏多少比例。

### 阶段 C：理解「策略在干什么」（第 1～2 个月）

目标：知道 Autopilot / 策略不是玄学，而是「周期看盘 → 决策 → 下单 → 风控」。

必学概念：

- 扫描间隔、决策日志、执行日志
- 置信度、仓位上限、最大持仓数
- Safe Mode / 交易阻断（系统自我保护）
- 信号、方向板、简报（Chat 工具也能练）

练习：读一条真实 Decision / Execution 记录，用自己的话复述「AI 为什么开/平」。

### 阶段 D：补金融与市场常识（持续）

目标：建立长期框架，而不是只会点按钮。

建议主题（每周挑一块）：

- 风险与期望：盈亏比、胜率、为什么高胜率也可能亏钱
- 波动与流动性：滑点、深度、为何小币更危险
- 宏观一点就够：利率、风险偏好如何间接影响加密（先定性，不追预测）
- 行为金融：FOMO、报复性加仓、报复性交易——对照自己的冲动

## 4. 术语速查（小白版）

按「交易时最常撞见」分组。每个词：**是什么 → 为什么重要 → 在 Strand 哪里看**。

### 4.1 账户与资金

| 术语 | 是什么 | 为什么重要 | 在哪看 |
|------|--------|------------|--------|
| **现货 Spot** | 买了币就持有，一般无强平 | 风险通常低于杠杆合约 | 交易所现货账户 |
| **合约 / 永续 Perp** | 用保证金赌涨跌，可多可空 | 可放大收益也放大亏损 | Hyperliquid / CEX 合约 |
| **钱包 Wallet** | 你掌控私钥的链上地址 | 私钥 = 资产所有权 | Config / 钱包连接 |
| **Agent 授权** | 允许程序代你下单，通常不能提现 | Strand 在 HL 上的安全模型核心 | 顶栏钱包 / Preflight |
| **保证金 Margin** | 开仓抵押的那部分资金 | 亏光保证金 → 接近强平 | 账户 / 持仓 |
| **权益 Equity** | 账户大约值多少钱（含未实现盈亏） | 看总体盈亏的主数字 | Portfolio |
| **可用余额 Available** | 还能用来新开仓的钱 | 为 0 就开不了新仓 | Portfolio / 交易所 |
| **未实现盈亏 uPnL** | 仓位还没平，账面浮盈/浮亏 | 会随价格跳动 | 持仓表 |
| **已实现盈亏 Realized** | 平仓锁定的盈亏 | 才是「落袋」结果 | 统计 / 历史 |

### 4.2 方向与仓位

| 术语 | 是什么 | 为什么重要 |
|------|--------|------------|
| **做多 Long** | 认为会涨；涨赚跌亏 | 最常见的方向 |
| **做空 Short** | 认为会跌；跌赚涨亏 | 合约特有能力 |
| **开仓 / 平仓** | 建立仓位 / 结束仓位 | 平仓才结算盈亏 |
| **杠杆 Leverage** | 用少量保证金控制更大名义仓位 | 10x 时行情反 10% 可接近爆仓量级 |
| **名义价值 Notional** | 仓位规模 ≈ 价格 × 数量 | 杠杆 × 保证金 ≈ 名义量级 |
| **仓位 Position** | 当前持有的某一合约敞口 | Portfolio 核心列表 |

### 4.3 价格与风险

| 术语 | 是什么 | 为什么重要 |
|------|--------|------------|
| **标记价 Mark** | 用于计价盈亏/风控的参考价 | 强平多看标记价，不只看最新成交 |
| **强平 Liquidation** | 保证金不足，仓位被强制平掉 | 杠杆交易最大生存风险 |
| **滑点 Slippage** | 下单价与成交价的偏差 | 波动大或流动性差时更明显 |
| **回撤 Drawdown** | 从高点回落了多少 | Strand 可用最大回撤硬闸暂停新开仓 |
| **日亏限制** | 一天内相对日初权益亏到阈值 | 防止「一天打穿」 |

### 4.4 订单与执行

| 术语 | 是什么 | 何时关心 |
|------|--------|----------|
| **市价单 Market** | 尽快按市场价成交 | 要速度，接受滑点 |
| **限价单 Limit** | 指定价格或更好才成交 | 要价格，可能不成交 |
| **TWAP** | 拆成多笔、按时间均价执行 | 大单减少冲击 |
| **Ladder** | 阶梯挂单 | Trade 里常见的计划类型 |
| **手续费 Fee** | 成交成本 | 高频/小利润策略会被手续费吃掉 |

### 4.5 AI / Autopilot 相关

| 术语 | 是什么 | 为什么重要 |
|------|--------|------------|
| **Autopilot** | 按周期自动决策并交易的交易员 | Strand 全自动路径 |
| **扫描间隔** | AI 多久看一次市场 | 太密费 AI 费；太疏可能慢半拍 |
| **决策日志** | AI「想了什么」 | 学习与审计的第一手材料 |
| **执行日志** | 实际下了什么单 | 对照「想」与「做」 |
| **Safe Mode** | 连续失败后保守停开新仓 | 系统在保护你 |
| **Preflight** | 启动前检查钱包/余额/授权 | 半配置上线是小白最常见事故 |
| **Claw402 / AI 费用钱包** | 付「思考费」的 Base USDC | **与交易保证金分开**，别混为一谈 |

## 5. 怎么「在交易过程中」学金融知识

### 5.1 把每次交易变成三道题

1. **风险题**：最坏亏多少？触达强平/日亏闸了吗？  
2. **结构题**：这是现货还是合约？杠杆几倍？名义多大？  
3. **决策题**：开仓理由是什么？若理由消失，是否该平？

答不全 → 说明还缺哪块知识，下周就专攻那一块。

### 5.2 用 Chat 当私人助教（只读）

示例提问：

- 「用零基础能懂的话解释：标记价和强平价有什么关系？」  
- 「我的权益从 100 掉到 90，回撤是多少？和日亏有何不同？」  
- 「市价单和限价单在波动剧烈时各自的风险？」

要求它：**先给生活类比，再给正式术语，最后给在 Portfolio（资产）哪里看。**

### 5.3 建立你的「术语本」模板

```text
日期：
场景：（例：Portfolio 看到未实现盈亏为负）
术语：
我的理解：
仍不懂：
下次要验证：
```

### 5.4 推荐自学资源类型（不绑定单一网红）

| 类型 | 学什么 | 注意 |
|------|--------|------|
| 交易所/官方文档 | 账户、费用、强平规则 | 以你实际用的场所为准（HL / Binance 等） |
| 入门金融读物 | 复利、风险、期望值、分散 | 选「概念书」，先别追预测 |
| 波动与订单 | 订单簿、滑点 | 看演示视频比干读有效 |
| Strand 自己的日志 | 决策与执行 | **最贴近你真实账户的教材** |

警惕：保证收益、带单玄学、「稳赚模版」——把它们当广告，不当课本。

## 6. 小白安全清单（贴在显示器旁边）

1. 只用亏得起的钱；先当学费。  
2. 杠杆从低开始（很多新手应从「接近无杠杆心态」练起）。  
3. 私钥 / API Key 不外传；Agent 不可提现 ≠ 可以无脑授权一切。  
4. AI 费用钱包和交易保证金分开看余额。  
5. 没过 Preflight 不要强行启动。  
6. 看不懂持仓表，就不要加仓。  
7. 设置并理解日亏 / 回撤硬闸。  
8. 情绪上头时先暂停（Portfolio 的 pause 是朋友）。  
9. 每周只复盘，不追涨杀跌式「补课」。  
10. 睡眠不足不做杠杆。

## 8. 常见误区

| 误区 | 更准确的理解 |
|------|----------------|
| 「AI 会替我保证赚钱」 | AI 是执行助手；风控与仓位大小仍是你的责任 |
| 「杠杆高才叫会玩」 | 生存率优先；杠杆是放大器，不是水平证明 |
| 「浮亏不算亏」 | 未实现盈亏会影响保证金与强平；心理上也应当真 |
| 「背完术语就会交易」 | 术语是地图；判断力来自复盘与风控习惯 |
| 「所有币逻辑一样」 | 流动性、费率、波动差很大；先熟一个大品种 |
